# 持仓顾问

入口：工作台选择“持仓顾问”，或者直接打开 `http://127.0.0.1:8839/#/holding-advisor`。

首版支持沪深 A 股的波段和中期持仓咨询。填写准确股票、每股成本、总股数、券商显示的可卖股数及账户总资产；今日买入数量需从可卖数量中排除。总资产包含其他持仓，但本轮仅计算这一只股票的暴露。默认单股上限 10%、本笔风险预算 0.5%、分批比例 50% 都是可改的执行偏好，并不是投资名人的原始阈值或已经验证的盈利参数。费用为用户假设，以实际券商账单为准。

## 回答依据

1. 复用现有 InvestmentRequest v4：真实行情、复权、财报、业务、日频资金、适用政策和技术辅助，由现有 Planner、Analyst、Verifier、Writer 形成并复核方向、支持、反证及失效条件。
2. 复用当前已发布知识快照。每轮持仓回答绑定固定规则 ID、版本、原文来源，以及完整公开研究的 SHA256。没有另建游离的名人提示词库，也不从新收到的博主观点直接发布规则。
3. 本地 Decimal 引擎将风险、容量、预期退出和原路线纪律应用于当前持仓，计算仓位上限、至风险参考的损失、假设费用、可卖数量和情景净额。成本用于盈亏试算，不是强制回本目标。
4. 买入条件未满足不单独触发持仓卖出；20 日低点为风险复核参考，高点为观察位。质量成长不以高点机械止盈；趋势路线只有额外转弱条件才考虑分批。各条件数量分别试算，不相加，成交后须更新输入。

股票研究和持仓建议都仍是未验证的条件研究。跳空、跌停、停牌、滑点和流动性不足可能导致不能按参考价成交；系统不下单。

## 对话与更新

- 支持“到什么条件卖”“下跌怎么办”“是否补仓”“方法依据”等持仓主题，以及“那跌到 78 元呢”或单独填写假设价格的情景试算。自由文本数字不会自动修改成本和股数，请使用表单明确更新。
- 每轮读取最新可得报价并封存。收盘、休市或来源失败的日期与状态会明确显示；来源失败时仅可用旧研究收盘价，不冒充盘中实时行情。
- 普通追问复用上次固定公开研究，重新读取报价和计算本地输入；勾选“更新公开资料”会建立新的公开研究，旧报告保留。不能在同一持仓对话中暗改股票、周期或原路线。
- 如果报价与原研究复权口径冲突，数值价位条件停止使用，需更新研究；仓位与资料局限仍展示。
- 每轮独立 `RUN-HA-*`，通过 `previous_run_id` 串联；历史库与页面刷新均可回看。最多一百轮，可另开咨询继续，旧记录保留。
- 当前咨询不会自动跟券商成交同步，也不自动买卖。多只股票及完整账户相关性请使用 [账户调仓](alphaagent-portfolio-advisor.md)。

## 隐私与可靠性

资金、成本、股数、可卖数量和自由文本问题保存在原本地 SQLite/CAS，不发送给 DeepSeek。模型只接收独立公开研究上下文。原研究最多 24 次模型调用、60000 令牌、900 秒；失败自动有限续跑仍使用同一预算和检查点。已完成研究及咨询不可覆盖，读取时复算本地结果并核对来源；同一 HTTP 请求内只核验一次共享研究，下次读取重新校验。模型遗漏技术或政策引用时反馈会累计，不能放松引用门槛。

API：

- `POST /api/quant/holding-advisor/turns`：创建首轮或追问，`request_key` 幂等。
- `GET /api/quant/holding-advisor/turns/{run_id}`：固定本轮与前序对话。
- `POST /api/quant/holding-advisor/turns/{run_id}/resume`：保留输入和既有预算继续。
- `GET /api/quant/holding-advisor/turns/{run_id}/export`：导出私有咨询 JSON；完整公开研究核验包从关联投资研究导出。

写入限本机同源。开发者查看 `?developer=1#/holding-advisor/{run_id}` 中的知识版本、公开研究绑定、费用和交易条款；正常用户页面只展示建议、条件、理由和反证。旧 5.2 回测门禁、下一交易日预测和每日更新方式不变。

数据继续使用 `alphaagent.local.json` 指定的已有数据库与配对 CAS；备份和服务器迁移沿用每日运行文档，不能只搬前端或只复制 SQLite。
