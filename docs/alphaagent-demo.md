# AlphaAgent 实际功能演示

## 现场入口与点击顺序

[打开工作台](http://127.0.0.1:8839/)。保持 Vue 3、原型图表与深浅主题。

1. 输入“全面分析美的集团”或沪深 A 股名称 / 六位代码。三个卡片是示例入口，研究入口不以三个卡片为白名单。
2. 看五个角色执行：Planner 识别范围与证券，Data 制定受限工具计划，Python 采集和计算，Analyst 引证分析，Verifier 独立复核，Writer 组织获准结论。执行记录中可查看真实模型、用量和请求 / 输出哈希。
3. 看最新报价、财务、历史 PE、K 线 / 均线 / 成交量、两融、工业 DCF、单股模拟。逐模块显示实际数据日期、缺项和方法适用性；不使用旧报告或虚构值填补新请求。
4. 点“证据 F…” / “证据 J…”查看事实或检索片段，带字符位置、获取时间、上游链接和 SHA256。当前 RAG 使用有界词法检索，公告正文为供应商转载，并非原始公告独立数值核验。
5. 美的 DCF 前五年增长率由 8% 改为 12%，点“重算并保存新版本”；也可调整均线 / 成本。它复用同批输入，保留父版本，旧模型解读不会复制到改变参数后的版本。
6. 在新版本下追问“结合公告和财报，解释当前估值假设与主要风险”。新的五角色任务重新取数，继承父版本参数；旧数值不进入本轮事实。父任务记忆只含显式关联的标的、问题、重点和参数。
7. 从历史库回看、刷新和导出；回看不触发新取数。点“重新采集并研究”才生成新的采集任务。
8. 上游或模型失败时看明确失败记录；点“继续未完成的研究”复用已成功的工具步骤和模型结果。若源码 / 依赖锁变化，要求新建研究，避免混合执行环境。

报价每 30 秒刷新，并可手动刷新；报告计算绑定本次输入，不随顶部报价自动重算。周末 / 休市显示上游最近交易报价，财报和两融各自遵循披露周期。

## 面试可讲的取舍

- **模型负责解释，Python 负责数字。** 原型计算代码不可移植；复用本项目内核。TTM = 最近完整年报 + 本年累计 − 上年同期累计；单季由累计差分；ROE 明确累计净利 / 平均归母权益。
- **受监督的多角色工作流。** 各角色有独立提示词与 Pydantic 输出契约，同一配置模型按依赖执行，Supervisor 执行工具白名单。Data 的三项基础工具为报告完整性所必需；不是任意代码执行或自由多 Agent 辩论。沿用现有模型适配器，不为这一条链路再叠加一个框架。
- **有界 RAG 和显式父任务记忆。** 本轮披露三表与公告正文检索保留字符定位，不新增向量数据库；不宣称已实现 Embedding 检索或跨会话自动长期记忆。
- **证据约束与独立复核。** 未知 ID、无出处数字被拒绝。引用原文数字逐字绑定到片段，不能自行舍入；Verifier 还要检查单位、时间、主体及推断。角色复核不能将供应商 MATCH 升级成权威 VERIFIED。
- **版本与恢复优先。** 既有数据库登记作业、内容寻址存储保留输入 / 产物 / 调用；UUID 幂等、完成记录不可修改、成功步骤复用。当前按单进程本地服务、单个活动研究设计，尚非分布式任务队列。

DCF 是合并工业 FCFF 代理：金融子公司未拆分，年度账面现金 / 债务 / 少数权益桥接，分母为最新全部发行股数（含 A/H），不扣库存股数量，不将库存股账面金额当作股数。它是参数条件情景，不是目标价。

单股均线模拟采用前日信号、次日开盘、三种成本独立计算，基准为沪深300价格指数，Sharpe 采用零无风险利率。前复权价格、连续仓位与尚未齐全的历史限制不能证明可交易全收益，不替代正式 PIT 回测。

## 数据范围仍保留

动态双股新采集比较与5.3软件执行链已接通。全市场财报修订链、完整公司行为、历史成交限制和全收益独立核对的真实档案仍未齐备。[5.2 历史输入档案](http://127.0.0.1:8839/#/backtest/RUN-HIST-3e21f847661e46c9)继续执行严格准入，不凭单股演示生成正式全市场收益。

旧 RUN-QUANT 报告回看校验冻结输入和产物；环境不同显示提示，重新执行 / 复算仍要求匹配环境。旧实时文件兼容只读，新研究使用共享数据库及既有 blob 存储，不改写历史哈希。

## 启动与验收

在仓库根目录运行：

```powershell
.venv/Scripts/python.exe scripts/serve_quant_o.py --data .phase3-quant-o/alpha-history-real-02 --port 8839
.venv/Scripts/python.exe -X utf8 scripts/verify_alpha_research.py --output .phase3-quant-o/my-new-research-check
```

服务复用现有模型配置，不输出凭据；缺少模型时返回明确错误，不生成假的 Agent 报告。验收脚本会实际调用现有模型并获取免费上游数据。`--reuse CODE=RUN` 可继续检查已由脚本创建的任务，避免因浏览器检查中断重复创建模型作业。

验收证据和本地数据位于忽略目录 `.phase3-quant-o`，不随 Git 分发。最终验收结果见 `docs/superpowers/plans/2026-10-10-alphaagent-unified-agents-results.md`。


## 本轮新增的完整演示路径

1. [功能与数据接入](http://127.0.0.1:8839/#/delivery)：按六步顺序演示，下载两种接入合同。
2. [最新双股比较](http://127.0.0.1:8839/#/compare)：输入两只沪深 A 股名称或代码；查看双方真实五角色、五维对照、六项补充指标和共同窗口曲线。数字可以点击查看依据。TTM ROE、净现比缺少匹配输入时明确留空。
3. [本轮真实比较记录](http://127.0.0.1:8839/#/compare/RUN-COMP-ddfd157e25434b4997fbb5c3ff1fc18b)：中际旭创 / 新易盛，两侧均完成五角色，640个共同交易日。曾出现无出处数字被门禁拦截、免费报价超时，失败被记录而不是用缓存冒充成功；恢复后仅重跑未完成部分。
4. [完整策略执行](http://127.0.0.1:8839/#/strategy)：确认 PE、ROE、收入增速、成本、现金和无风险假设。服务端未安装完整审核包时保存缺项，不生成收益；可刷新、回看和导出。
5. 合格包接入后的同一页面会执行年度筛选、公司行为账本、三成本、五项绩效、四曲线、年度展开及逐笔明细；离线复算与独立参考分别显示。隔离测试环境已用于开发验收，合成收益不会装进演示库。

一次只运行一个新采集或计算任务。报告使用本次采集输入，顶部报价定时刷新；休市显示最近报价，各类报表按披露周期更新，没有承诺交易所实时行情 SLA。
