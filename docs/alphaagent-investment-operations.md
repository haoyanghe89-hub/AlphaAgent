# AlphaAgent 投资知识与计划运行说明

当前日常应用的启动、09:25行业清单、自动核对和迁移说明以 [日常运行说明](alphaagent-daily-operation.md) 为准。以下保留投资知识与研究的操作细节。Vue 3、SQLite／CAS、既有行情通道及 Planner／Analyst／Verifier／Writer 保留。原型样式及旧单股、比较、DCF、策略、下一交易日实验继续使用。

## 启动及正常使用

在 `D:\deepsearch` 打开 PowerShell，已有服务可用时直接访问8839，不重复启动。

```powershell
./start-alphaagent.ps1
```

浏览器访问 `http://127.0.0.1:8839/#/`。工作台可以提出明日预测、未来三个月研究、市场观察、行业候选，或“投资计划 美的集团 招商银行”等问题。投资计划还可以直接访问 `#/investment-research`，填写一至四只准确名称或六位代码，选择波段／中期及交易日数量。

当前可运行投资路线为趋势波段和质量成长；价值预期、政策事件等知识可以作为有来源的研究参考，不冒充已验证可交易路线。金融企业不套用非金融合并财报指标。未填资金时不输出个人仓位；填写资金与持仓后只在本地计算约束，不发给模型。

用户页查看明确方向、支持／反证、条件、价格和指标图、资金与政策证据。“技术辅助”展开MACD／RSI／ATR，辅助解释不改变原路线门槛。资金各供应商及日频／分钟口径分开；缓存、封存截止与实时不能混称。

## 前瞻核对与恢复

新投资研究在开始时登记前瞻协议。运行中的后台会有界自动核对，也可点击“核对最新真实行情”；只追加本次观察，原判断不变。尚未到期显示等待，缺数、停牌和失败保留；不会生成假成交、回填历史成绩或自动调整阈值。

原文字反证需要新资料验证；收盘价格、成交额与受控路线条件可按日频观察。方向是否符合、条件是否触发及是否实际成交分别看待。费用虽已冻结，当前没有模拟收益；正式收益回测仍需通过原5.2历史档案及独立全收益核对。

服务中断后，重新打开原研究并点击恢复，可复用已保存资料及获准步骤。超预算记录不重置计费；另发请求会产生新的独立记录。K7方法比较是本地显式CLI，没有自动后台循环。

## 开发者入口与资料补充

`http://127.0.0.1:8839/?developer=1#/delivery` 查看K7封存验收、三组方法对照和导出。`?developer=1#/knowledge` 查看内置方法、原文、实际读取范围和版本。开发者参数只切换展示，不授予发布权限。

后续可在对话中提供财经博主的原文、链接、转录和时间。按照 [知识补充接口](alphaagent-knowledge-supplements.md) 保存候选，核对原出处、条件、反例及适用数据，再走K2双职责审核。开发者可把真实复盘保存为待审核候选，不能直接发布或自动调参。

## 数据与模型连接

配置文件 `D:\deepsearch\.env`；Tushare读取 `TUSHARE_TOKEN`，模型使用项目现有DeepSeek配置。不要截图或发送完整密钥。已有授权只涵盖公开研究材料，账户、资金、持仓及股数不进入模型。

2026-10-17早间验收曾遇到Tushare官方HTTPS证书错误，09:49严格复测已恢复；随后行业、日线和资金接口实源成功，并追加了成功的观察记录。旧失败事件与K7当时的健康封存仍保留。没有降低TLS校验、明文发送Token或更改历史采集时间。

手动安全探测（不发送密钥）可执行：

```powershell
.venv/Scripts/python.exe -c "import requests; print(requests.get('https://api.tushare.pro', timeout=15).status_code)"
```

验证TLS正常后，再通过真实数据请求检查业务权限。积分不能等同所有接口授权；没有拿到的新数据始终按原合同报缺项。

## 导出、备份及恢复

研究页“导出核验包”保存原文、报告、模型调用和观察。研究核验包可能含用户声明资金与持仓，应作为本机私有材料保存。K7导出包仅包含此次公开材料方法对照及验收证据，不含资金画像。

离线核对：

```powershell
.venv/Scripts/python.exe scripts/verify_investment_research_export.py <研究核验包.zip>
.venv/Scripts/python.exe scripts/verify_alpha_knowledge_release.py <K7核验包.zip>
```

不要只复制SQLite，必须同时保留数据库引用的CAS原文。复用 `marketpulse.investigation.operations.backup.backup` 和 `verify` 创建并核验配对备份；`drill` 只恢复到一个新建隔离目录。当前收尾演练位于 `.phase3-quant-o/investment-knowledge-20261017-07/`，没有覆盖在用数据库，没有网络重放、定时任务或交易执行。

`knowledge-release.json` 是本机交付记录指针，原记录已进入数据库审计表和CAS。复制环境时应保留该指针，或用已核验的release_id重建指针；K7导出包也可独立离线核验。恢复演练目录带隔离标记，不应直接作为活动服务执行外部请求。
