# 结论速览：面向初学者的研究解释

本轮按用户认可的“判断＋理由＋后续观察条件”改造现有实时研究报告，保留 Vue 3、原型四类编号卡片、深浅色和原始证据。没有把本轮 UI/解读改造算作 5.2 全市场数据建设已完成。

## 已实现

- 第一屏明确区分经营增长、价格历史位置、近期走势、估值贵便宜。每张卡片展示依据和后续观察条件，关键数值可点击。
- 后端以报告保存的前复权收盘计算近 52 周区间、距最高收盘回落及区间位置；均线采用同一日线日期。刷新顶部报价不改写报告判断。
- 历史 PE 分位使用本次有效自算正值样本，并公开窗口、样本数、公式及最新查询版本/PIT 限制；不宣称上市以来分位，不把样本偏低称为确认低估。
- 收入与归母净利按相同累计期间解释，单季同比与上年同季增速对照单独展示；不由增速差臆测毛利、费用或业务原因。
- DCF 复用既有 Python 折现内核，展示前五年现金流增长假设上下各 4 个百分点的压力测试，其余参数固定。不是预测、合理价区间或目标价。金融企业保持工业 DCF 不适用。
- 可展开查看供应商公司简介、条件情景、判断尚缺的依据、完整模型报告与所有原指标。业务收入拆分、同行同口径比较、行业需求和权威核验尚缺时明确展示。
- 新研究将可复算解读追加到 Agent 事实证据中，保留原 F 类编号；Analyst/Verifier 指令要求解释意义并区分事实、估值与未来条件。
- 旧报告通过独立只读 `/api/quant/research/runs/{id}/overview` 展示当前版本解读，并返回输入结果引用。原始结果 blob、哈希、模型结论不重写；导出包含判断和观察条件。
- 解读端点失败时保留真实原报告与图表，明确显示解读未加载。

## 规则与边界

- 价格窗口为报告日线截止日向前 364 个自然日，含首尾共 52 周；区间仅用前复权收盘，不用盘中高低价。
- 区间位置低于 33% 为偏下，高于 67% 为偏上。窗口首样本距起点超过 14 天或有效样本少于 120 个，不判断一年位置。这是展示规则，不证明完整交易日档案或未来回报。
- 近期偏弱要求收盘 < MA20 < MA60；偏强要求收盘 > MA20 > MA60，其余明确为信号不一致。无效末日数值不回退为旧值。
- PE 至少 120 个正值样本、跨度至少一年，末值必须与报告指标一致；未来日期剔除。不是严格 PIT 历史估值证明。
- 原有严格数字引用与独立复核保持。真实自测曾拦截模型将 `8.0` 写成 `8`；改成可逐字引用的标准百分比表达，并增加回归测试，未放宽校验。
