# AlphaAgent 原型前端与单股闭环实施计划

> 执行方式：使用 executing-plans 在本会话逐项执行，自测后等待用户点击验收。

**Goal:** 以原型替换前端产品界面，打通提问、确认单股范围、真实执行、报告、个股与历史回看。

**Architecture:** Vue 3 保留，重新实现原型页面；轻量 hash 路由保证刷新可恢复且无需改动静态服务。后端增量提供只读概览、原始问题和持久化职责过程，沿用现有取数、确定性计算、独立核验和报告链。旧事件调查界面退出入口，历史数据不删除。

**Tech Stack:** Vue 3、Vite、ECharts、FastAPI、SQLAlchemy、Node test runner、Playwright。

**Spec:** ../specs/2026-10-06-alphaagent-redesign.md；原型 03-ux-design.md 及实际 frontend/src 页面与 global.css；用户补充：原前端无需保留，允许优化。

## Global Constraints

- 原型计算代码不得移植或复制；本步不新增财务公式，不宣称权威财报校准完成。
- 最终保持 multi-agent；过程必须记录真正执行的规划、Data、Analyst 工具、Verifier、Writer 职责，不能用计时模拟进度或将节点完成伪装为指标 VERIFIED。
- 深色精确沿用 #0a0d12 / #10141b / #161b25 / #e8b046，增加浅色适配；13px 基准、报告 14px/1.7，保留 A 股涨红跌绿。
- 新任务始终明确股票、日期和复权；历史冻结窗口由用户选择。追问版本、对比和回测在后续阶段实现，本步不能静默丢弃对应要求并启动普通单股任务。
- 真实数据缺少时显示缺项；错误可重试；异步切换不得串页；刷新与浏览器返回可恢复。
