## 故障事实

用户任务 RUN-DEC-5dfa816a30b84181840503bfa10fca4b 已取得并封存宁德时代公司披露、行情及补充输入，失败点为 Planner 模型调用。原记录四次请求均未取得有效模型响应；旧错误仅保存 ProviderCallError/TimeoutError，页面错误文案却泛称资料核查未完成。

现场小请求复现 DeepSeek HTTP 503 和超时；模型列表与账户余额接口可读取，账户可用。Flash 与 Pro 都未能在有界实测中返回正文；流式请求虽取得 HTTP 200 响应头，也未在限制时间内返回模型内容。没有据此推断供应商全球状态。

旧 Planner 预留为每次 12734 令牌，四次失败累计保守预留 50936；没有使用量响应，不代表实际账单。原“继续未完成步骤”在原任务累加失败预算，代码版本改变后还会被恢复门禁拒绝。因此不能依靠重复点击恢复来解决。

## 已实现修复

- 区分暂态传输失败与输出格式错误。暂态失败使用相同封存输入重试，不再添加“修正数字”的格式提示。每次实际尝试仍计入调用与保守令牌预算，不自动重置预算，不无限重试。
- 保存允许公开的错误分类和 HTTP 状态，禁止持久化异常原文、请求头或凭据。页面明确提示模型连接恢复，而非错误归因于取数；等待时展示最近日期的已取得资料，不作为完成复核的投资判断。
- Planner 只接收公司、问题、期限及已准入方法等规划信息；完整资金窗口、政策和知识原文不再重复放入规划请求。分析与复核仍使用封存证据，事实、引用、期限和反证门禁保持不变。
- 中期研究可在主模型暂态失败后使用备用模型；实际响应模型写入首次观点，切换及原始模型正文保留。已完成 Analyst 后不切换分析/复核模型。固定正式日预测实验保持原模型协议；自主选股探索和行业候选支持独立备用服务。
- 新增 POST /api/quant/decision/runs/{id}/retry，以请求 UUID 幂等创建新记录。通过完整性核验后复用原始证据及来源检查点，旧失败记录、原预算和历史内容不覆盖。没有可复用封存输入时重新取数；损坏输入拒绝复用。
- 前端“继续研究”保留重试 UUID，丢失响应不会重复创建任务；错误时保留已取得资料，成功提交后跳转新记录。原研究已完成时不会被此入口改写。
- 新增独立 OpenAI 兼容备用传输，配置只从服务端本地环境读取。原始正文归档、共享预算、输出结构和事实核验一致；备用客户端在任务结束时关闭。未配置时不发出任何备用请求。
