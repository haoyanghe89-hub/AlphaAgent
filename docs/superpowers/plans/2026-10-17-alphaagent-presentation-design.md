# 日常使用展示统一

按用户已授权的展示优化执行，保留 Vue 3、原型风格、全部研究能力、固定历史与5.2门禁。本轮只改前端展示和导航，不重写报告、计算、模型提示或数据库。

沿用现有蓝黑／浅灰底、金色操作、红涨绿跌。正文使用系统中文字体，数字保留等宽与对齐；统一24px页标题、16px区块标题、13–14px正文、12px数据说明。1320px阅读宽度，12–16px区块间距，表格在自身区域滚动。

阅读顺序：页标题与数据时间 → 一句话结论及主要建议 → 关键数字、图表 → 入退场或操作条件 → 可展开的理由、反证、方法与来源 → 历史、追问。已完成报告的输入表单默认折叠，仍可修改并生成新记录。

首页先展示市场热点，盘前关注保留全部候选但用紧凑列表呈现依据，资金曲线与盘后资金榜保留。全部研究类型从工作台进入，历史库继续跨功能搜索分页。

新增统一开发者工作区，接续现有developer=1展示参数。调用、预算、哈希、验收状态、内部知识及接入合同只在开发者视图显示。本页分析入口保留原ID与必要查询参数；展示切换不增加发布或交易权限。

按真实旧报告检查四项核心结果及市场、候选、估值、比较、策略、历史、开发者页面。检查主题、窄屏、展开／收起、引用、追问输入、开发信息隔离与历史哈希，之后再交用户验收。
