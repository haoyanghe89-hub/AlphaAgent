# 第 1、3 项：统一研究与真实多 Agent 验收

## 已交付

首页名称 / 代码、股票页、新采集、显式父任务追问进入 `/api/quant/research` 同一服务；`/api/quant/live` 为同一处理器的兼容别名。腾讯证券目录与东方财富公司资料共同确认证券及财务类型，三个首页卡片只作示例。免费来源参数化后支持沪深 A 股单股最新研究；身份、必要价格或样本不足明确失败，可选字段缺失按模块展示。

既有数据库增加 `inv_quant_research_run`，迁移版本 `20261010_10`；复用既有内容寻址 blob 存储及模型适配器。模型是现有配置 `deepseek-flash`，五角色有真实结构化调用、用量与输入 / 输出哈希；工具执行、数值计算与模型解释分开。无模型配置不能启动假的 Agent 任务。

Planner 限定标的和范围；Data 在工具白名单中提供计划，基础采集、计算、披露检索是单股报告必需步骤；Analyst 引证，Verifier 独立检查推断，Writer 仅排列通过复核的结论。当前是有状态的受监督顺序工作流，未引入新的框架或分布式队列。

RAG 对保存的公告正文及最新披露利润表片段进行有界词法检索，保留字符定位与内容哈希。模型数字使用事实占位符，或逐字绑定到所引证据的数值位置；未知引用和自造数字拒绝。父任务记忆有界，仅传标的、原问题、重点和参数，追问重新采集；调参版本不保留旧模型解读。

完成任务不可覆盖；幂等键重试不多建版本；中断与重启保留成功步骤，模型 / 工具调用中断状态真实显示。恢复核对实现和依赖锁，环境变更要求新任务。旧 Quant 报告回看保留冻结输入与产物校验，展示环境差异，复算 / 重新执行仍严格检查环境。
