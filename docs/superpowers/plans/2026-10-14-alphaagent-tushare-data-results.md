## 实现与可靠性

- 复用受控 HTTPS、固定接口、来源预算、取消检查及内容寻址归档。凭据只在向官方 HTTPS API 发出请求时从本地配置读取，禁止携带凭据重定向。公开请求定义、缓存索引、原始响应和页面均不保存 Token；上游错误或回显凭据的正文不归档。
- 新增 Tushare 响应缓存，六小时内复用同一 API/参数/字段对应的封存原文，保留原始采集时间并核对内容哈希；过期不冒充新数据。日线以 17:30 后才纳入当日收盘的保守规则选窗，仍须实际返回有效数据。
- 新研究采用独立 SW2021 协议，旧东方财富分类和旧报告按原版本读取。候选内部适配视图只在内存中用于复用计算，归档始终是实际 Tushare 表格；证据定位到真实 `/data/items/行/列`。
- 成交额由千元换算为元，总市值由万元换算为元，换算规则、原始字段与发行人绑定后再核验。数值重建不依赖模型生成。
- 财务原始多版本全部保留。候选源 v2 按官方 `update_flag=1` 选择唯一可用最新版；多个最新版仍保留冲突，不任意取第一行。原始行索引保持不变，未把现在取得的修订版包装为严格历史时点可知。
- 证券简称只兼容交易所 N/C、U/W 显示标记，保留原始名称；不剥离 ST 或任意容忍公司改名。
- 提示词 v4/v5/v6 分别保留，已完成记录和已完成角色检查点不改写。v6 要求明确、有条件的方向和非空字符串，保留无依据估值高低、满产、机构意图及错引事实的门禁；预测价值仍为 UNVERIFIED。

当前接入覆盖行业扫描与候选研究。旧正式量化 `TushareAdapter` 入口仍保留原准入阻断，没有以新接口可读为由放开旧 5.2。各旧功能统一迁移、收盘后持续采集、盘前预检、独立备用供应商和更完整的来源权限/频次监控仍是后续数据保障工作；本轮未创建定时任务。
