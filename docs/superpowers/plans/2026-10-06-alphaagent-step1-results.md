# AlphaAgent 第一步自测与人工验收

日期：2026-10-06。分支：`codex/alphaagent-step1`。本步只修复运行环境、补充实施与评测约束，尚未重构原型界面；没有提交或推送。

## 修改与根因

标准 `.venv` 原先未安装量化依赖，也缺少 Windows 时区库。量化调整测试因 `ZoneInfoNotFoundError: Asia/Shanghai` 失败；既有完整量化环境中同组 83 项测试通过。现在基础依赖显式包含 Windows `tzdata`，锁文件仅增加相应依赖边；按锁文件安装 quant extra，并在 README 说明 Python 与可选依赖要求。

重构规格与现有评测文档增加“禁止移植原型计算代码”及人工样本、权威披露口径、可复现性三项分别验收的要求。自动权威基准核对尚未实现，现有未验证状态未升级。最终仍为 multi-agent 架构。

## 用户点击验收

打开 **http://127.0.0.1:8831**，该服务仅绑定本机，使用复制的隔离数据库，未修改原业务数据库。

1. 点击左侧平安银行／美的集团／贵州茅台档案，进入“报告”，查看行情、估值和财务图表。
2. 展开图表数据，点击数值查看冻结计算单元格；点击正文引用查看证据弹窗。
3. 切换浅色／深色，调整窗口宽度，检查图表和弹窗。
4. 点击“新建调查”→“量化投研”，搜索 `000001`，选择平安银行，再明确选择已有历史冻结窗口，启动任务；完成后点击“阅读报告”。当前窗口为历史数据，不能当作今天的行情。
5. 刷新页面，从左侧历史档案重新打开刚生成的报告。

页面新建任务的自动验收记录：`RUN-QUANT-516229682dd14008`，报告 `RPT-716af84a3e75`。后端任务已完成；浏览器脚本摘要中的 `status: CREATED` 是启动响应的状态，不是最终状态。
