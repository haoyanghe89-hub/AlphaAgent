# 5.2 全市场采集与覆盖账本

> 使用 executing-plans 执行已批准的 5.2 范围；不提交、不推送、不改变准入标准。

**Goal:** 把单股公开源核验扩展为绑定历史父版本、可停止和续采的全市场分区任务。真实完整档案通过才完成 5.2。

**Architecture:** 从冻结基本目录及逐年名单取并集，保留区间内上市后退市的证券及身份未知记录；不依赖三股演示目录。冻结查询清单和父报告哈希，响应按内容寻址保存，数据库记录请求、分区、失败和批次。每批仍最多 24 次、180 秒、16 MiB；全任务可分批续采。公开源原始观察不自动生成 STRICT 审核凭证。

**Tech Stack:** Python / FastAPI / SQLAlchemy / Vue3 / pytest / Playwright。

**Spec:** `docs/superpowers/specs/2026-10-06-alphaagent-redesign.md`；`2026-10-09-alphaagent-52-completion.md`。

- [x] `market_plan.py`：历史范围、去重分区、原始行情/分红/逐年财报查询及逐股覆盖；未知身份保留，退市保留，响应校验。
- [x] `market.py`：持久化、UUID 幂等、批次预算、停止与中断恢复、源哈希校验、导出。公开请求不能缩小股票范围或提交通过声明。
- [x] 原型报告内加入全市场覆盖与采集入口；复用配色、布局，支持深浅色和窄屏。
- [x] 合成边界测试：退市/年内短暂上市/未知记录、漏分区、空响应、跨股票污染、预算、失败续采、重启、篡改；真实免费源小批验证后记录全量任务剩余规模。
- [x] 检查原计划四项真实档案及独立核对，记录实际缺口，未通过不能勾选 5.2 或生成收益。
