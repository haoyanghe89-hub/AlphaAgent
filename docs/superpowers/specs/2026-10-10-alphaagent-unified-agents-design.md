# 统一实时研究与真实 Agent 接线

用户已批准同时完成上一轮建议的第 1、3 项，顺序由开发者决定。本轮在现有分支与已修改工作区继续，不提交、推送或复制原型算法。

## 目标与边界

单股研究从首页自然语言、证券页、历史重开、情景重算进入同一服务。证券由免费上游动态解析，支持沪深 A 股，不把固定三只名单当全市场。不适用的分析方法和上游缺失分别显示原因。保持 Vue 3、原型图表、浅深主题及原始输入可审计。

接入真实 Planner、Data、Analyst、Verifier、Writer 角色：各自具有独立结构化模型契约与提示词，Supervisor 按依赖调度。模型仅选择受限工具和引用已有证据；Python 工具计算全部数值。复用现有 OpenAICompatibleModelAdapter、Settings 与模型重试判断，不另引入模型 SDK。记录调用模型、开始结束、用量、请求与输出哈希及工具结果。模型未配置或执行失败不能冒充多 Agent 完成。

## 服务与存储

推荐在已交付实时链路上提取共享研究服务，旧 live 地址作为兼容别名；新入口使用 /api/quant/research。另一方案是扩大旧 QuantRun 工具链，但其历史输入契约尚不包含实时三表与资金面；继续两套独立入口会重复编排。本轮采用前者并共享原有数据库、模型适配器和内容寻址存储。

任务登记持久化到现有数据库的新研究表，输入/结果/调用内容使用现有 SHA256 blob 存储。旧实时文件只读导入兼容，旧 QuantRun 报告仍使用其自身证据校验。历史读取检查产物与冻结输入，不要求当前源码等于历史源码；重新执行及复算继续要求匹配历史环境，环境差异明确提示。

请求包含 UUID 幂等键、问题、可选代码和父任务。服务端证券解析拒绝指数/基金、歧义和未支持市场。单任务有界模型调用、总令牌、来源数量、网络时间和响应体积。中断任务保留已完成步骤，恢复复用已冻结输入及成功模型调用，不在读历史时重新取数。

## 数据和计算

证券身份、交易所与财务类型由上游确认。行情/K线/财报/估值/两融/质押/解禁查询参数化。必需身份及价格失败阻止结果；可选来源失败保留逐模块 UNAVAILABLE。银行和保险不运行工业 FCFF；工业财务字段缺失不能补零。TTM、平均权益 ROE、自算 PE 和四态核验规则沿用现有约束。

RAG 从本次保存的披露资料及公告正文分块检索，保留来源哈希、页或字符定位；使用有界词法检索，暂不增加嵌入服务。引用检索资料不等于数值获权威原文校准。记忆只取显式父任务的有限上下文，旧数值不得替代本轮新输入，报告保留父版本。

Analyst 产生带证据 ID 的解释；Verifier 独立检查引用与推断，但不能将供应商一致升级为权威 VERIFIED。财务数字优先使用服务端事实占位符；引用正文中的数值必须逐字匹配所引片段，并记录数值在片段中的字符位置，不能自行计算或舍入。Writer 仅排列通过检查的结论，不改写和添加事实。未知引用、无依据数值被拒绝；数字绑定仍需 Verifier 检查单位、时间及语义，不能单凭字符串相等判定正确。资料及问题内容作为数据，不能增加工具权限。

本地执行预算为单个活动任务、十分钟、最多十次模型调用、累计令牌阈值 26000、每次输出上限 2400 tokens、每次模型调用不超过 120 秒。来源最多 24 个非重复响应、累计 16 MiB，每个网络响应上限 3 MiB；公告最多尝试四篇、保留两篇正文。累计令牌在发起下一次调用前检查，最后一次实际用量可能超过阈值，不宣称供应商计费硬上限。恢复同时核对实现与依赖锁哈希；环境变化要求新建任务。

## 验收

至少真实运行美的、格力、茅台及银行：代码/名称输入、最新取数、适用图表、行业方法边界、实际模型调用记录、证据定位、追问记忆、调参、历史回放及导出。测试歧义股票、错误证券、缺失来源、模型故障/无密钥、无效引用、幂等、恢复、篡改与旧环境回看。浏览器检查完整点击及深浅/窄屏。5.2 全市场历史准入和正式回测不因此完成。
