日期：2026-10-13，Asia/Shanghai。

状态：用户于 2026-10-13 明确回复“开始吧”，本增量获准实施；能力完成状态以开发结果与验收记录为准。本文补充已确认的 P0–P7 设计，不重做原计划，不修改既有研究或预测记录。在 P4 与 P5 之间先交付一条可用的选路与政策证据闭环，再供 P5 候选比较复用。

## 用户目标与已确认范围

丰富系统可追溯的投资方法、书籍方法笔记、行业知识及政策资料。分析股票时，先根据实际业务、经营特征、研究期限和可得数据选择方法，再取证、计算、分析和复核。

用户已确认：政策首期以中国国家级政策为主，同时纳入与公司业务直接相关的海外政策。普通用户继续看简明结论、原因、反证和变化条件；方法选路、未用原因、来源覆盖和核验过程在开发者视图展示。

保留 Vue 3、现有原型风格、四角色 Multi-agent、有限补证循环和不可变记录。保留当前必须给明确研究方向的协议；方法缺项降低支持程度，不靠捏造事实维持方向。完全没有可审核事实时按现有失败门禁处理。下一交易日实验与中期研究独立，不因新增方法而回改原实验、原预测或旧 5.2 准入。

## 已核对的基础与缺口

- `decision/method_cards.json` 已登记 M01–M08，但文本步骤和来源登记不等于可执行模块。
- `decision/methods.py::select_methods` 目前只检查 scope、有限期限规则和输入名称，不按公司主营业务、经营阶段及政策敞口选择方法。
- `decision/industry.py::business_role` 只从公司简介识别设备、制造或未配置；P4 设备模板条件启用，不能扩写成全行业覆盖。
- Planner 当前只输出研究问题；`forecast.method_versions` 主要按阶段固定列方法，尚不是实际执行日志。
- `EvidenceItem`、CAS、原文定位、时间过滤、补证、Verifier 和版本台账可复用。目前没有专门的政策有效性及公司适用性合同。
- 旧量化模块已有 PE / ROE / 营收增长筛选、技术指标和部分估值计算；它们不能代替完整因子检验或已验证投资策略。

## 采用方式

采用“结构化知识与方法注册表 + 确定性准入 + 模型选择和解释”。沿用现有代码的证据和审核路径。

把所有书籍和政策直接塞入提示词，容易混用业务、时点和期限；首期也不要求新建向量平台或微调模型。先使用标签、来源和全文关键词检索，保留以后替换检索器的接口。方法实际需要的数据和计算仍由受控工具提供。

## 三类资料分别管理

### 方法知识

保存原始作者 / 机构、资料或书名、版本、实际读到的章节 / 页码 / 网页段落、提炼规则、适用对象、所需输入、步骤、反例、禁止推断和审核记录。自写方法笔记用于选择和执行研究，来源本身不能增加当前公司的事实支持数量。

书籍可以逐步整理，但必须标记覆盖程度：仅元数据、已读公开片段、已提炼部分章节、已审核方法。不能把模型已有常识或找到一本书的链接，写成整本书已经读取并入库。优先从可合法获取的原始内容与公开作者资料提炼，不将未经许可的整书全文作为默认采集目标。

首期丰富的研究线路包括：

| 线路 | 方法来源方向 | 数据和执行边界 |
|---|---|---|
| 经营质量、竞争优势与现金回收 | 巴菲特公开股东信、AQR 质量研究 | 财报原文可支持有限经营分析；标准化质量计算须另验输入 |
| 价值、安全边际和估值 | 格雷厄姆 / 巴菲特相关原始资料、已有估值工具 | 待实际定向阅读并审核；低 PE 不自动等于低估 |
| 成长与合理价格 | 林奇相关原始资料、增长质量研究 | 待定向阅读；区分可持续成长与周期高点，不凭概念定成长股 |
| 价格隐含预期与预期差 | Mauboussin / Rappaport《Expectations Investing》公开资料、既有 R02 | 书籍与既有 Mauboussin / Callahan 论文分别记录；缺假设不运行逆向估值 |
| 周期、市场环境与风险 | Howard Marks 公开备忘录、行业供需资料 | 中周期利润不能直接外推；价格、经营和风险分别观察 |
| 因子与趋势 | AQR、French、中国市场因子研究 | 指标计算、筛选、因子检验、组合策略分别标级，不把文献结果当本系统收益 |
| 行业机制、政策和事件 | 行业机构、政府原始文件、公司披露 | 必须证明公司业务连接；关联不能升级为因果或已兑现收益 |

这是待逐项落实的资料与方法范围，不宣称上述作者的完整体系已实现。某条线路可以先只有研究笔记；未经可执行合同与样例核验，不能被模型调用为已启用方法。特殊资产、金融、分红等方法后续按实际资料与独立模板扩展。

### 行业与公司知识

保存业务链条、盈利驱动、关键经营指标、同行可比条件、风险和例外。标签允许多业务、多地区和未知，不强迫公司只属于一种类型。

分类首先依赖公司原始披露：主营产品 / 服务、收入结构、客户与供应链、资本开支、现金回收及财务特征。供应商板块名称只作线索。成长、周期、成熟现金流、经营修复等判断须有当期依据，不能仅凭公司名、股价涨幅或模型印象赋标签。

设备、制造、消费、银行等业务需要不同指标，这是计划适配示例，不是当前覆盖承诺。银行不能直接套工业公司现金流模型，制造不能照搬设备验收逻辑。无专用模板时可使用符合输入要求的通用方法，并明确专业覆盖不足。

### 政策事实

政策卡至少包括：发布主体、法域、文号、原文链接和定位、发布及取得时间、生效 / 过渡 / 到期时间、修订 / 废止关系、法律或文件状态、适用行业 / 产品 / 主体 / 地域、资格条件、执行细则及未知项。

分别处理正式文件、征求意见、机构解读和媒体线索。未知生效、废止或资格状态保持未知，不根据标题补齐。政策“发布”和“已对公司产生影响”是不同事实。

对公司影响采用“政策条款 → 公司业务敞口 → 可能影响收入 / 成本 / 资本开支 / 供给 / 竞争 → 实际兑现证据”的链条。每个连接分别绑定原文或标假设，同时查限制与反证。未取得公司资格、产品参数或地区敞口时，只能保留背景或待核对关系。

已核查的候选官方入口：

- [国务院政策文件库](https://www.gov.cn/zhengce/zhengceku/bmwj/home.htm)、[政府文件检索](https://www.gov.cn/zfwj/search.htm)。
- [工信部政务公开](https://www.miit.gov.cn/zwgk/index.html)：产业文件与政策查询。
- [美国 BIS EAR 官方入口](https://www.bis.gov/regulations/ear)：仅在公司产品、供应链或市场敞口相关时纳入，需核对正式条文与版本。

入口在本次通过公开网络检索核查；尚未建立生产适配器，未宣称批量采集成功或某项政策当前必然适用于中微公司。财政、税务、商务、货币及其他海外机构后续按研究需求逐源探测和接入，不先声称覆盖全部。

## 从一只股票到选定方法

1. **业务识别**：形成带引用的 `ResearchProfile`，包括行业 / 产业环节、业务与地区敞口、经营特征、研究期限、数据能力和未知项。
2. **筛选候选方法**：程序根据业务、期限、可执行状态和输入合同排除明显不适用的方法；模型不能自行创造可执行工具或补全输入。
3. **选择与取证**：Planner 从允许候选中提出主方法、辅助核对和反对视角，记录理由和资料需求。只使用少量互补方法；没有必要时不强凑数量，不做名人投票。
4. **补齐并重新准入**：按方法需求定向取财报、行情、行业或政策。重新检查主体、期间、币种、单位、覆盖和可得时点；输入名字存在不算输入质量合格。
5. **执行与复核**：数值由已批准计算器产生，Analyst 基于证据解释。Verifier 检查方法适配、实际输入、推断边界、政策状态和反证。方法意见冲突时说明冲突依据与当前取舍，不能平均成虚构综合胜率。
6. **保存使用记录**：封存每个方法的版本、选择 / 禁用理由、实际执行、输入证据、计算、输出判断及审核结果。记录当前真正用过的方法，不再用“阶段固定枚举”代替使用事实。

长期质量原则可用于短期风险背景，但不能独立支持下一交易日涨跌。政策生效日也不等于市场首次获知日；事件窗口使用可证明的公开时间，不能让盘后资料解释当天盘中行情。

建议新增 `ResearchProfile`、`MethodRoutingPlan`、`MethodExecutionRecord`、`KnowledgeNote` 和 `PolicyEvidence` 的独立版本合同。旧 M01–M08、旧合同及提示版本按原语义读取；新增方法 ID 和字段只进入新版本，不能改写旧 P4 数据或解除旧门禁。

## 第一次交付的可验收范围

先交付完整选路机制与半导体真实样例，避免等资料库全面建完才展示：

- 扩展后的方法条目能说明来源、适用业务、输入、执行能力和未启用原因；至少包含已实际读取原始资料的新增方法笔记，不只列书单。
- 同样的选路接口，给设备公司与制造公司不同主方法；混合业务和未知标签有明确降级。制造样例只验证选择与对应输入，不提前宣称 P6 制造模板完整启用。
- 中国国家级政策和一个相关海外官方来源进行真实探测、原文封存、版本与条款定位。没有匹配的政策如实留空；取得一条文件不等于当前公司获得政策利益。
- 生成一份新真实研究：用户看到政策 / 行业影响、支持与反证，开发者能看到为何选这些方法、实际用了哪些输入、哪些未执行。保存独立版本，不覆盖 P4。
- 用设备 / 制造误配、次日 / 中期误配、缺财务输入、政策仅征求意见 / 未生效 / 已替代、资格未知、同源转载、过时版本、原记录篡改等有针对性的样例检验门禁。
- 沿用原预算与来源白名单机制，定向检索，按资料新鲜度缓存；不新增遍历所有书籍 / 政策 / 股票的无界模型调用，不自动定时监控。
- 自测通过后提供用户与开发者页面、点击步骤和预期结果，再交用户验收。下一交易日实验继续保留；软件与方法适配测试通过仍不等于投资预测有效。
